Protocol laboratory

Inspect an undocumented TCP exchange: read the sessions, follow one direction byte by byte, describe the messages with a rule, and see where the rule holds and where it is contradicted.

  1. Open a capture. Upload a normalized JSON, or a raw .pcap/.pcapng that is normalized on upload.
  2. Pick a session and a direction. The hex view shows the bytes and, under them, the packet each byte came from.
  3. Describe the messages. Write a rule in the rule editor, or load the example rule that ships with the project.
  4. Apply the rule. Every message is classified: matched, mismatched, incomplete, ambiguous or uncovered. Mismatched messages are the counterexamples to look at first.
  5. Export the report. The interpretation of every session is written to a self-contained HTML page.
